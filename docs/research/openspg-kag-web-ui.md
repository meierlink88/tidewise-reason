# OpenSPG + KAG Web UI 核验

核验时间：2026-08-09

## 结论

OpenSPG + KAG 提供开源 Web 产品界面。官方 KAG 快速启动通过 Docker Compose 启动完整服务，默认访问 `http://127.0.0.1:8887`。

两类能力需要区分：

- OpenSPG 侧偏向知识建模、知识构建、图谱管理和查询。
- KAG 侧偏向知识库/应用管理、数据导入、问答、深度推理、查询过程分析、图索引渲染与来源引用。

因此它比单纯的图数据库浏览器更接近一套“知识构建 + 推理应用”的工作台。不过，它不是现有 Neo4j/Qdrant 的通用可视化客户端；已有数据需通过 OpenSPG/KAG 的导入、构建或存储适配机制进入其知识库，才会自然出现在界面中。

## 边界

- 官方材料可以确认产品模式 Web UI、知识库/应用管理、可视化查询分析和图索引渲染。
- 不能仅凭这些说明就认定它具备成熟企业产品所需的完整 RBAC、审计、HA 或任意外部图数据库即插即用能力；这些需要按选定版本实测。
- 默认账号和本地 Docker Compose 启动方式明显包含体验/开发用途，生产部署需要另做安全与运维评估。
