# GeopoliticRivalry 首批初始化候选目录

> 调研日期：2026-08-26  
> 目标：为 Tidewise `GeopoliticRivalry` 准备一批可持续维护的全球地缘政治/军事战争叙事蓝图。  
> 证据边界：仅使用联合国、东盟及直接当事国政府等一手官方来源；来源用于证明该长期议题在当前仍然存在，不代表 Tidewise 认可任何一方的事实或法律主张。

## 结论

建议首批初始化 **9 个 `ACTIVE` 蓝图**，覆盖全球投研传导中最关键的科技与半导体、能源、航运、军工、粮食及风险偏好通道。这些是“可以持续接收新 Event 的叙事锚点”，不是某次制裁、会谈、袭击或停火本身。

经用户审阅后采用的一期 Demo 集合：

1. 中美战略与科技竞争
2. 台海安全与两岸关系
3. 南海海洋权益与安全争端
4. 俄乌战争及俄西方安全对抗
5. 伊朗—美以及海湾安全对抗
6. 巴以冲突与加沙战争
7. 红海—也门航运安全冲突
8. 朝鲜半岛核与安全对抗
9. 刚果（金）东部—M23—卢旺达冲突

研究初稿曾将“印巴安全与克什米尔争端”列入第一期。用户审阅后，以对关键矿产供应链
更直接的“刚果（金）东部—M23—卢旺达冲突”替换；图谱初始化以审阅后的清单为准。

## 入选标准

一个 `GeopoliticRivalry` 应同时满足：

- **身份稳定**：主要行为方和核心争议可以跨越单条 Event 维持。
- **边界可辨认**：能说清哪些 Event 属于该蓝图，不能只写“中东局势”或“大国博弈”。
- **不等于结果变量**：“原油供应中断风险”“全球风险偏好下降”应是 Variable/Signal，不是地缘蓝图。
- **可持续更新**：新的会谈、制裁、军事行动、停火或政策转向能作为 Event 继续归入。
- **对投研有明确传导面**：至少对一类产业链、大宗商品或风险偏好存在可解释的传导路径。

### 1. 中美战略与科技竞争

- `name_en`: `U.S.-China Strategic and Technology Competition`
- `rivalry_type`: `GEOPOLITICAL`
- `description`: 中国与美国围绕技术领导力、半导体与 AI、关键供应链、贸易与投资安全以及战略影响力展开的长期竞争。不包含单独的台海或南海军事安全事件，这两类事件归入各自专项蓝图。
- `core_actors`: `中国；美国`
- `peripheral_actors`: `美国盟友与技术合作伙伴；中国的贸易与技术合作伙伴`
- `influenced_regions`: `[东亚, 北美, 欧洲, 东南亚, 全球]`
- `status`: `ACTIVE`
- 当前性依据：美国 2026 年《国家安全科学与技术战略》将“技术战略竞争”、半导体、AI、供应链韧性和保护敏感技术列入国家安全框架；中国商务部 2026 年 7 月的回应也显示美方对中国 AI 企业的调查和制裁议题仍在持续。[美国白宫战略文件](https://www.whitehouse.gov/wp-content/uploads/2026/08/NSSTS-082026.pdf)、[中国商务部答记者问](https://cacs.mofcom.gov.cn/article/gnwjmdt/sb/zm/202607/188743.html)

## 不建议初始化为 GeopoliticRivalry 的概念

| 候选词 | 不建议原因 | 正确归属 |
|---|---|---|
| 中东能源安全局势 | 是多条冲突的后果和上层汇总，主体与动作边界不清 | Storyline，或用多个 Variable/Signal 汇总 |
| 全球风险偏好下降 | 是变量的方向状态，不是地缘冲突 | Variable + Signal Fact |
| 霍尔木兹海峡通行风险上升 | 是由具体 Event 推导的传导变量 | Variable + Signal Fact |
| 美国扩大 HBM 出口限制 | 是一次具体政策动作 | Event，归入“中美战略与科技竞争” |
| 以色列袭击某伊朗设施 | 是一次可定位的现实动作 | Event，归入“美以—伊朗军事冲突” |

## 初始化前的数据门禁

1. 本次 Graphiti Demo 不写 PG，也不设置 `data_object_id`；未来正式数据的 `GPR...` ID 必须由 Data Service 创建并返回。
2. `influenced_regions` 上述值只是研究候选文本；真正入库前必须对齐 PG 已有 Region 标准名称，不应因名称不匹配在 Graphiti 新建 Region。
3. `core_actors` 和 `peripheral_actors` 是经审阅的文本字段，不自动证明 Country/Organization 关系。
4. 初始化的 GeopoliticRivalry 不应进入 Event 原生 `add_episode()` 的实体抽取范围；Event 与这些蓝图的归属应由后续受控分类工序完成。
5. `ACTIVE` 仅表示该叙事蓝图目前仍可接收 Event，不表示每一时刻都在发生高强度冲突；冲突强度应通过 Event 派生的 Variable/Signal 表达。
